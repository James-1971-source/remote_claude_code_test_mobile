# 📝 컬러 메모장

브라우저에서 바로 실행되는 색상 테마 메모장입니다. 설치 없이 `index.html`을 열면 됩니다. PC와 모바일 모두 지원합니다.

## 주요 기능

| 메뉴 | 기능 |
|------|------|
| 파일 | 새로 만들기, 열기, 저장, 다른 이름으로 저장, 인쇄 |
| 편집 | 실행 취소/다시 실행, 잘라내기/복사/붙여넣기/삭제, 찾기·다음 찾기, 바꾸기(모두 바꾸기), 줄 이동, 모두 선택, 시간/날짜 입력 |
| 서식 | 자동 줄 바꿈, 글꼴(종류·스타일·크기) |
| 보기 | 확대/축소(10~500%), 상태 표시줄, 줄 번호 |
| 색상 | 테마 6종(오션·포레스트·선셋·라벤더·로즈·다크), 글자색/배경색 사용자 지정 |

- 입력한 내용과 설정은 브라우저(localStorage)에 자동 저장됩니다.
- 상태 표시줄에 커서 위치(줄/열), 글자 수·단어 수, 확대 비율을 보여줍니다.
- Chrome·Edge에서는 파일을 그대로 덮어써 저장하고, 그 밖의 브라우저에서는 다운로드 방식으로 저장합니다.

## 단축키

| 키 | 동작 | 키 | 동작 |
|----|------|----|------|
| Ctrl+N | 새로 만들기 | Ctrl+F | 찾기 |
| Ctrl+O | 열기 | F3 / Shift+F3 | 다음/이전 찾기 |
| Ctrl+S | 저장 | Ctrl+H | 바꾸기 |
| Ctrl+Shift+S | 다른 이름으로 저장 | Ctrl+G | 줄 이동 |
| Ctrl+P | 인쇄 | F5 | 시간/날짜 입력 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 | Ctrl + + / − / 0 | 확대 / 축소 / 기본 크기 |

## 파일 구성

- `index.html` — 화면 구조(메뉴, 도구 모음, 편집 영역, 상태 표시줄)
- `style.css` — 색상 테마와 레이아웃
- `app.js` — 메모장 기능
